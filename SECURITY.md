# Security policy

Please do **not** report a suspected vulnerability in a public issue or PR.
Contact the maintainer privately at the address listed under `authors` in
[`pyproject.toml`](pyproject.toml), with reproduction details, affected versions
and potential impact. Allow time to assess and coordinate a fix before public
disclosure. Ordinary bugs and feature requests belong in
[GitHub Issues](https://github.com/IvanildoBarauna/currency-quote/issues).
